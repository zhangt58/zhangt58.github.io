## Today's Top 10 on Hacker News

### 1. [IRCv3](https://ircv3.net/)
⭐ 58 💬 38 👤 basilikum
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50041540)

IRCv3 is a set of backward-compatible extensions to the IRC client protocol developed by the IRCv3 Working Group to modernize Internet Relay Chat. It standardizes features such as SASL account login, account information, message tags, away notifications, server time, and message batching. The group is also working on account registration, chat history access, secure connection handling, Unicode names, and client avatars.

### 4. [Build your own decision model](https://nishtahir.com/build-your-own-decision-model/)
⭐ 323 💬 74 👤 softwaredoug
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50037949)

The article explains how to build a simple decision model by constraining a language model to choose from a fixed set of answer options. Instead of generating a full response token by token, the model scores only the allowed option tokens in a single pass and selects the highest-probability answer. A code example shows this approach using Qwen to answer a multiple-choice question, though the output probabilities are not guaranteed to represent true correctness.

### 8. [How big is a Git commit?](https://ratfactor.com/cards/git-commit-size)
⭐ 39 💬 19 👤 theanonymousone
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50017548)

A Git commit's size depends on how compressible the changed files are and on Git's use of zlib compression and, later, packfiles. Small commits can add several kilobytes of overhead due to object metadata and tree structures, while larger commits are stored very efficiently, often at 10% to 50% of their uncompressed size.

### 9. [Retrofitting language models to operate over bytes](https://www.nature.com/articles/s41586-026-11111-4)
⭐ 71 💬 7 👤 theanonymousone
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50001234)

The article argues that large language models are not fully end-to-end because they depend on subword tokenization, which can limit character-level understanding and shape model behavior. It proposes retrofitting existing models to process raw bytes instead of conventional tokens. This approach aims to make language models more end-to-end and reduce tokenization-related limitations.

### 10. [PSPi 6 – Raspberry Pi in a PSP](https://github.com/othermod/PSPi-Version-6)
⭐ 94 💬 9 👤 therepanic
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50038623)

The PSPi 6 is an open-source project that transforms a classic PSP 1000 into a modern handheld by replacing its mainboard with a custom circuit board that hosts a Raspberry Pi as its brain. It offers an 800x480 LCD display with adjustable brightness, battery monitoring, and PSP audio, while keeping all original controls. It fits Pi Zero, Zero 2W, and CM4 models and can run retro emulators as well as full Linux distributions, with the hardware released under a Creative Commons license.
