⭐ 21 💬 0 👤 patadune
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=49607991)

### 4. [I've factored the RSA keys of a Certificate Authority from the 90s](https://mcpherrin.ca/2026/09/07/rsa.html)
⭐ 357 💬 0 👤 ahlCVA
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=49604637)

The 512-bit RSA keys of a long-defunct certificate authority shipped with early Netscape browsers were factored on a desktop computer, allowing reconstruction of the private keys. This demonstrated that early web PKI roots used weak key sizes that are now easily broken. A test VeriSign code-signing key was also factored, highlighting the fragility of legacy cryptographic deployments.

### 5. [There's a new "Google Jail" for independent wikis](https://weirdgloop.org/blog/google-jail)
⭐ 191 💬 0 👤 pizzaiolo
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=49604870)

A recent change in how Google treats brand-new domains has created a “Google Jail” for independent wikis, where only the main page appears in search results for months or longer. Because most wiki traffic comes from Google, this has made launching new wikis on fresh domains very difficult. As a workaround, hosts are placing new wikis on subdomains of established domains to get indexed, with plans to move them to their own domains later once search visibility is established.

### 9. [TALA Is Open-Source](https://d2lang.com/blog/tala-is-open-source/)
⭐ 235 💬 0 👤 alixanderwang
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=49604150)

TALA, Terrastruct's AutoLayout Algorithm, is now open-source under the MPL-2.0 license and is bundled with D2 as an alternative layout engine. It is an orthogonal autolayout algorithm designed for software architecture diagrams, optimizing aesthetics such as symmetry, flow, and clustering while allowing users to pin or partially specify node positions. The release highlights comparisons with Dagre and ELK, but notes tradeoffs including randomness, weaker DAG handling, and slower performance on large diagrams.

### 10. [How well do agents use test/verification techniques?](https://danluu.com/agentic-testing/)
⭐ 92 💬 0 👤 vinhnx
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=49605246)

The article evaluates whether coding agents improve implementation correctness when prompted to use specific testing or verification techniques, including TDD, property-based testing, fuzzing, formal methods, and various Rust testing libraries. Across many prompt conditions, no technique dramatically outperforms the default, and agents generally use the tools superficially, producing low-value or irrelevant tests. The findings suggest that simply instructing agents to use a named testing method does not reliably improve software quality.
