### 3. [A real Linux kernel, compiled to WebAssembly](https://github.com/pithings/unkernel)
⭐ 47 💬 9 👤 DonAtimator
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50533945)

unkernel is Linux 7.x built as a single WebAssembly module with a real MMU — the kernel (syscalls, scheduler, memory management, ext4, TCP/IP) is compiled code, not emulation, so it boots to a shell in under a second. Only user programs are emulated: unmodified aarch64 binaries, so Alpine and Debian packages run as-is, entirely in the browser with no install or server.

### 4. [Harsher on Male? Evaluating LLMs on Gender-Asymmetric Moral Framing in Conflicts](https://arxiv.org/abs/2606.14068)
⭐ 38 💬 10 👤 rzk
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50597743)

This study examines whether large language models judge identical negative behavior differently based on the actor's gender. Using a gender-mirrored benchmark of conflict scenarios, it finds that models consistently apply harsher, more punitive and blame-centered framing to male actors, while treating female actors with more empathy and therapeutic language. The pattern persists across model families, scenario types, and reasoning styles.

### 5. [Lean verification of the Riemann Hypothesis](https://leanprover-community.github.io/blog/posts/riemann-hypothesis/)
⭐ 1064 💬 884 👤 g-b-r
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50589618)

The Lean and Mathlib communities certify that a 17-million-line Lean proof of the Riemann Hypothesis is correct. They verified that the formal statement matches the established hypothesis, that the code compiles, and that the proof passes multiple independent checkers, including Lean's kernel and external proof checkers. The result is presented as a major milestone in machine-checked mathematics.

### 7. [Inkling-2-Mini in 5.4 GB Memory](https://github.com/ShinMegamiBoson/lookatmyquant)
⭐ 479 💬 120 👤 k__
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50591853)

LookAtMyQuant is a quantization compiler that measures how much each stored piece of a model hurts the output when compressed, then picks a code for each piece so the whole model fits a size budget with the least damage. On Gemma 4 E2B its GGUF has 12x lower KL divergence than Q4_K_M at the same file size, and v2 takes Qwen3.5-4B to 1.23 GB (2.3 bits/weight) while still solving 330 of 540 exact-answer math problems — the post's Inkling-2-Mini build runs in 5.4 GB.

### 8. [Self-hosted library branch over public web OPDS](https://joinmayberry.com/)
⭐ 12 💬 0 👤 philips
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50566495)

Mayberry is an open-source system that lets individuals host a private, self-managed ebook library branch from their own computer using a local ePub folder. Friends and family can be granted access with anonymous library card IDs and browse the collection through any OPDS-compatible e-reader or app. The service emphasizes privacy by using encrypted outbound tunnels, no DRM, no user tracking, and no central storage of books.

### 9. [Show HN: The Riemann Proof Handbook](https://github.com/tamnd/riemann-handbook)
⭐ 59 💬 27 👤 tamnd
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50596664)

The Riemann Handbook is a book (PDF and EPUB) that writes the Lean proof of the Riemann Hypothesis from tamnd/riemann-lean as mathematics — definitions, theorems, lemmas and their proofs, in words, across four volumes. The author is explicit that the underlying claim is not independently checked: nobody has built the full Lean project yet, so the book explains the code rather than verifying the mathematics.

⭐ 625 💬 391 👤 beginning_end
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50588982)

The U.S. Army plans to detonate a large stockpile of lead azide, a highly shock-sensitive primary explosive used in munitions primers, near Burlington, Iowa.
