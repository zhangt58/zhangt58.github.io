### 8. [TCP Use-After-Free: CVE-2026-98432 / CVSS 9.8](https://atlasum.net/blog/cve-2026-98432-linux-ipv4-tcp-uaf)
⭐ 540 💬 249 👤 oger
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50319143)

CVE-2026-98432 is a critical use-after-free vulnerability in the Linux kernel's IPv4 TCP handshake that can be triggered remotely without authentication. It can lead to kernel memory corruption, information disclosure, or remote code execution, and a proof-of-concept root exploit exists for servers using multipath TCP listeners. Fixed stable kernel releases are available, but some major distributions remain affected.
