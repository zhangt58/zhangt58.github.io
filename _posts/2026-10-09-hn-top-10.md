### 3. [Whistle: Speech to Text in 16.9 MB](https://cactuscompute.com/blog/whistle)
⭐ 786 💬 156 👤 gmays
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50008427)

Whistle is a compact 16.9 MB open speech recognition model designed to run directly on CPUs for mobile, wearable, automotive, and embedded devices. It transcribes up to 30 seconds of audio in seven languages, provides word-level timestamps, and can generate speech embeddings without sending audio off-device. The model uses the same C++ engine and quantization as Needle, enabling fast on-device transcription and integration with tool-call workflows.

### 4. [MXC - a sandboxed code execution system](https://github.com/microsoft/mxc)
⭐ 52 💬 16 👤 nreece
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50016489)

MXC (Microsoft eXecution Container) is a cross-platform sandboxed code execution system for safely running untrusted code — model output, plugins, and tools — on Windows, Linux, and macOS. It offers multiple containment backends, from OS-native process sandboxes (Windows Sandbox, LXC, Bubblewrap, Seatbelt) to full MicroVMs (Nanvix, Hyperlight), behind a unified containment model and typed SDKs. Sandboxing is policy-driven, with filesystem (read-only / read-write / denied) and network (proxy, outbound) controls.

This article compares keyboard handling between Windows and Macs, focusing on confusing key names such as Backspace/Delete, Enter/Return, and Numpad Enter.
