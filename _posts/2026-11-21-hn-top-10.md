### 2. [Levent Alpöge claims proof of the Generalized Riemann Hypothesis [pdf]](https://alpo.ge/remark.pdf)
⭐ 2687 💬 1876 👤 iamronaldo
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50574968)

A claimed proof of the Riemann Hypothesis and the Generalized Riemann Hypothesis is announced, with the argument developed using Claude and formalized in Lean. The method extends beyond classical function-field techniques by combining Fourier-analytic ideas with automorphic structures, including chained theta lifts, to address prime-counting bounds. The proof is described as long but complete in formalized form, with plans to simplify and explain it.

### 3. [Inkling 2 Mini](https://thinkingmachines.ai/news/inkling-2-mini/)
⭐ 1064 💬 200 👤 jasondavies
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50581260)

Inkling 2 Mini is a small, open-weights AI model designed to run locally on laptops, using a looped transformer architecture to improve reasoning and coding performance while keeping its memory footprint around 20GB. It outperforms comparable open models under 100B parameters on agentic coding benchmarks and is available for inference and customization. A variable-loop research variant is also released to study how repeated reasoning passes affect performance and monitorability.

### 4. [RCE in Gnupg](https://lists.gnupg.org/pipermail/gnupg-announce/2026q4/000517.html)
⭐ 47 💬 3 👤 gdgghhhhh
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50587208)

GnuPG has released GPGME 2.3.1 to fix a critical double-free vulnerability in all earlier versions. The flaw can be triggered by an OpenPGP key with a crafted long user ID and may allow data exfiltration or, in some cases, remote code execution. Users should update GPGME and dependent applications such as Gpg4win, GnuPG Desktop, mail clients, and Samba.

### 6. [ClawDOS – An AI coding agent for DOS](https://ricapar.net/ClawDOS/)
⭐ 85 💬 23 👤 Ricapar
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50586292)

ClawDOS is an AI coding agent that runs on original IBM PC XT hardware under DOS, allowing users to converse with Claude to read and edit files, write Turbo C programs, compile them, and run them. A native DOS harness handles the API and tools while a modern bridge PC manages TLS, showing how current AI can operate within the severe constraints of 1980s computing.

### 7. [We promoted developers into architects without informing them](https://manidoraisamy.com/developer-to-architect.html)
⭐ 463 💬 252 👤 QueensGambit
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50579331)

The article argues that many developers are being pushed into architect roles without preparation, especially when using AI coding tools. AI tends to implement stated requirements literally, prioritizing security and compatibility over performance, which can create slow or redundant systems. To avoid this, teams need to explicitly define architecture, data models, and constraints before asking AI to generate code.

### 8. [Unforced Navier-Stokes Singularity and the Generalized Riemann Hypothesis](https://terrytao.wordpress.com/2026/11/20/unforced-euler-singularity-unforced-navier-stokes-singularity-and-the-generalized-riemann-hypothesis/)
⭐ 467 💬 191 👤 archon1410
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50578358)

New results report finite-time blowup for the unforced three-dimensional incompressible Euler equations and for the unforced three-dimensional Navier-Stokes equations, with proofs supported by AI and formalized in Lean. A separate Lean-only proof of the Generalized Riemann Hypothesis has also been generated, relying on modern Langlands and arithmetic geometry ideas. The Navier-Stokes and Riemann Hypothesis proofs still require further verification and human-readable exposition.

### 10. [Clojure will affect the way you think about programming (2017)](https://eli.thegreenplace.net/2017/clojure-the-perfect-language-to-expand-your-brain/)
