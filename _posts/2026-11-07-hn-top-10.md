### 1. [Every Mac comes with an (undocumented) family member classifier](https://8rank.ai/game/apple-intelligence-personal-knowledge-graph)
⭐ 119 💬 40 👤 infwhispers
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50403097)

Modern Macs include undocumented background daemons that build a personal knowledge graph by analyzing local data such as contacts, calendars, photos, messages, mail, location, and screen time. The graph stores relationships between people, places, apps, and events, including inferred family ties, in a local database that can be queried by on-device AI features. Researchers have examined the system, released a tool for inspecting it, and warned that a compromised knowledge base could create serious privacy and safety risks.

### 8. [Port 0: The Port That Does Not Exist](https://acid.vegas/blog/the-port-that-does-not-exist/)
⭐ 10 💬 4 👤 NewCzech
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50403063)

Port 0 is technically reserved and normally used by operating systems as a request for an ephemeral port, but network packets can still carry it as a destination. Because most tools and scanners ignore it, the article describes a full IPv4 scan that found hidden services, including an IRC network, listening on port 0. The findings show that this overlooked port can be used to conceal network activity.

### 9. [The Components of Agent Memory](https://www.anthropic.com/research/components-of-agent-memory)
⭐ 60 💬 31 👤 geoffbp
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50402212)

The article explains how AI agents can build memory by combining immediate logs with offline consolidation, similar to how human brains replay experiences during sleep. It introduces memory notes and salience tagging as ways for Claude to store useful facts, and describes dreaming as a process that reorganizes past interactions into more reliable long-term knowledge. The key idea is that agent memory works best when it predicts what future tasks will need and integrates that knowledge across sessions.
