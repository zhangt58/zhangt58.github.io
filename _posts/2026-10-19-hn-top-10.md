## Today's Top 10 on Hacker News

### 1. [Linux 7.3 Released](https://lwn.net/Articles/1101143/)
⭐ 236 💬 107 👤 cjd8
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50149392)

Linux kernel 7.3 has been released, marking a record-setting update with 18,765 non-merge commits from 3,021 developers, including 807 first-time contributors. The release adds major features such as binfmt_misc extensions, group-scheduling improvements, the failfs filesystem, fchroot, BPF per-CPU data, and completed sched_ext support. It also includes ntfs3 alternative data-stream support, SMB server enhancements, and virtual machine working-set tracking.

### 2. [Hybrid Reasoning Agents: LLM agents that think in latent space, act through text](https://arxiv.org/abs/2610.18861)
⭐ 407 💬 199 👤 allinonai
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50145337)

Hybrid Reasoning Agents combine latent-space thinking with text-based action, allowing LLM agents to reason internally while still using tools and communicating through language. The system uses a lightweight HybridLink and continuous working memory to switch between modes, plus post-training methods that teach when to think latently and when to act in text. Across benchmarks, it improves performance over text and latent agent baselines while reducing tokens, speeding inference, and lowering cost.

### 3. [How to Train Your Robot](https://www.construction-physics.com/p/how-to-train-your-robot)
⭐ 46 💬 15 👤 crescit_eundo
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50104874)

Recent AI progress has been driven by scaling models, datasets, and compute, with language models benefiting from vast existing text corpora. Robotics faces a harder data problem because there is no comparable public stock of high-quality robot action data, so finding or generating enough examples is central to training effective robot-control models. The core challenge is obtaining large amounts of correct behavior data to train and evaluate models through repeated comparison and adjustment.

### 7. [If you don't run your own LLM proxy, how do you know whats going on?](https://jrdsgl.com/if-you-dont-run-your-own-llm-proxy-how-the-fuck-do-you-even-know-whats-going-on/)
⭐ 180 💬 127 👤 amrrs
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50145507)

The article argues that relying on a third-party LLM frontend or provider dashboard hides important operational details, so developers and teams should run their own LLM proxy. A self-hosted proxy gives a single controlled endpoint, detailed logs, virtual API keys, multi-provider and multi-model routing, and faster switching without reconfiguring everything. This lets engineers inspect token usage, cache misses, and request paths to make better decisions about AI infrastructure.

### 8. [Tmux and Claude Code: Sessions, Send-Keys, and the Ceiling](https://crystl.dev/guides/tmux-for-ai-agents/)
⭐ 39 💬 21 👤 ankitg12
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50148855)

Tmux pairs well with AI coding agents because it keeps long-running terminal sessions alive, organizes multiple agents in named sessions, and allows scripts to send input or capture output. Claude Code now includes a built-in --worktree --tmux option for creating isolated single-agent sessions, but it does not cover multi-agent layouts, remote orchestration, or interactive monitoring. For those needs, developers must build custom tmux workflows, while also recognizing the practical limits of tmux as an agent-control layer.

### 9. [Someone behind the software](https://karrisaarinen.com/posts/someone-behind-the-software/)
⭐ 456 💬 167 👤 tosh
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50142573)

Good software carries the perspective, experience, and values of its makers, not just the output of a standardized process. The author argues that treating product development as a factory, especially with autonomous agents, can create additive, incoherent products that lack a unifying point of view. Instead, making software should preserve the creator’s judgment and care so the product feels shaped by someone rather than assembled by many.

### 10. [Laptop Based on 6502 CPU](https://www.maddox.pro/?p=448)
⭐ 139 💬 61 👤 nanochess
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50111537)

A maker has completed the LT6502b, a compact laptop built around a 6502 CPU, featuring a translucent orange case, a 10.1-inch 1024x600 IPS display, a 10 MHz processor, an on-board SID emulator, and Wi-Fi.
