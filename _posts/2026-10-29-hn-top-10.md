## Today's Top 10 on Hacker News

### 1. [Qwenputer: A functioning, deterministic RISC-V CPU inside Qwen3.5](https://divagr.com/blog/qwenputer)
⭐ 493 💬 104 👤 csmantle
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50282838)

Qwenputer is an experimental Qwen 3.5 4B model with a deterministic RISC-V CPU compiled into its weights, allowing it to execute arithmetic, C, and MicroPython during forward passes without external tools. It uses the model’s Gated DeltaNet attention layers as RAM by configuring their state matrices for exact row-wise reads and writes. The piece also explores related ideas, including using RNN state to hide reasoning and embedding tamper-resistant monitoring tools in model weights.

### 2. [Zero click, silent, remote Android DoS](https://smsofdeath.com/)
⭐ 106 💬 57 👤 MarkBlah
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50285452)

A zero-click vulnerability in Android's telephony stack allows a remote attacker to send a specially crafted WAP Push SMS that crashes the phone's telephony process without user interaction. The crash drops active calls, including emergency calls, and repeated messages can corrupt the SMS database, leaving the device unable to make or receive calls until repaired. The issue affects multiple Android devices and can be triggered silently with no visible notification.

### 3. [Why is this fingerprinting script creating bioweapons?](https://nullpt.rs/fingerprinting-bioweapons)
⭐ 1268 💬 241 👤 hazebooth
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50276998)

A researcher reverse-engineered browser fingerprinting scripts by crawling thousands of websites and capturing canvas-based fingerprints. One script contained alarming function names referencing lethal ricin and aspirin dosages, which the author suspected was anti-LLM obfuscation designed to make AI tools refuse to deobfuscate it. The article explores how such misleading identifiers can interfere with automated analysis.

### 4. [Getting debug access on a Brother printer over Telnet](https://inventor7777.github.io/blog/2026/10/22/debug-access-on-brother/)
⭐ 60 💬 15 👤 inventor7777
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50243757)

The article explains how to obtain and analyze Brother printer firmware to find a Telnet-based debug console on an MFC-L8900CDW. The author downloads the firmware using Brother’s update API, then uses AI-assisted reverse engineering to identify a TRON-family T-Kernel real-time operating system. This reveals hidden system internals and a path to deeper debug access beyond the vendor CLI.

### 5. [Forging a Microsoft Edge Full Chain with Logic Bugs Only](https://blog.orange.tw/posts/2026-10-the-last-proof-of-human-craft-browser-full-chain/)

### 6. [MiniLake Is a Local Databricks API Emulator with SQL, Delta Lake and Spark](https://dmux.github.io/minilake/)
⭐ 24 💬 2 👤 kermatt
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50259697)

MiniLake is an open-source local emulator for the Databricks API that runs real SQL on DuckDB, real Delta Lake files, and real Spark jobs in containers. It lets developers point Databricks SDK, CLI, Terraform, Asset Bundles, and LLM agents at a local endpoint without cloud accounts, API keys, or billing. The tool also includes Unity Catalog support, a built-in SQL workspace, MCP tools, and air-gapped Docker deployment.

### 10. [A new faster algorithm to compute 64-bit signed floor division](https://www.benjoffe.com/fast-floordiv)
⭐ 71 💬 5 👤 benjoffe
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50256409)

The article presents a new algorithm for fast 64-bit signed floor division when the divisor is known at compile time, addressing a gap in compilers and libraries that often use slower or buggy methods. It benchmarks the approach against existing techniques and shows it can improve throughput on ARM and many x86 cases while maintaining competitive latency. The method also supports other bit widths and can be applied to related operations such as positive-modulus and Euclidean division.
