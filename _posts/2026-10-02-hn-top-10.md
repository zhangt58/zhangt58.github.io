## Today's Top 10 on Hacker News

### 1. [Pi 1.0](https://earendil.com/posts/pi-1-0/)
⭐ 1335 💬 423 👤 sergiotapia
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=49926069)

Pi 1.0 is a stable, minimal, and extensible agent harness that adds features such as Codemode, MCP support, virtual models, deferred tool loading, and an improved terminal experience. It is designed to remain simple while supporting agentic coding and application building. Alongside it, Pi Durable is an experimental package for creating longer-running agentic applications with the same minimal, flexible principles.

### 4. [Show HN: Audionaut – an open-source cross-platform multitrack audio editor](https://github.com/kvoltmer/Audionaut)
⭐ 19 💬 5 👤 vltmrkls
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=49931031)

Audionaut is a free, open-source multitrack audio editor written in C++ on the JUCE framework, running natively on Windows, macOS, and Linux. It offers precise cutting, per-track playlists, multi-channel support, and clean exports for music, podcasts, and multitrack recordings — without the weight of a full DAW. A standout feature is MCP support, letting AI agents like Claude drive the editor so each edit arrives as a single undo step.

### 5. [Clef: Open-weight decision models, and new RL fine-tuning platform](https://blog.cloudflare.com/clef-decision-models/)
⭐ 524 💬 182 👤 jasondavies
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=49923692)

Cloudflare has released Clef and Clef-flash, open-weight decision models that generate fast, structured, bounded outputs for agentic workflows and are hosted on Workers AI as well as open-sourced under an Apache 2.0 license. The models are positioned as alternatives to large language models for tasks requiring quick, reliable classifications, such as routing support tickets or assessing website domains. Cloudflare also introduced a reinforcement learning platform that lets customers fine-tune Clef for specific use cases.

### 7. [How Singapore's government-run dating service works](https://www.singapore-samizdat.com/p/how-singapores-government-run-dating-service-firstdate-works)
⭐ 180 💬 144 👤 danielfoster
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=49929113)

Singapore's GovTech has launched a pilot government-run dating service called FirstDate, initially limited to government workers. It verifies users through Singpass, matches them in cycles using the Gale-Shapley Stable Marriage Algorithm, and shares contact details only when both parties agree. Participants complete a detailed questionnaire covering interests, lifestyle, habits, and relationship preferences.

### 8. [SvelteKit 3](https://svelte.dev/blog/sveltekit-3-is-here)
⭐ 288 💬 106 👤 sampsn
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=49926536)

SvelteKit 3 is the latest major release of the official Svelte application framework, offering improved type safety, cleaner configuration, and easier migration from earlier versions. Key changes include moving configuration to vite.config.ts, replacing the $lib alias with lib, and enhancing environment variables, service workers, and error handling. Remote functions remain a top priority but are not yet ready, requiring experimental Async Svelte support.

### 9. [Pi Durable](https://earendil.com/posts/pi-durable/)
⭐ 394 💬 50 👤 paulsmith
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=49925969)

Pi Durable is an experimental agentic framework shipped alongside Pi 1.0 by Earendil, built for long-running, durable agents that can run anywhere there is a JavaScript runtime. It shares Pi's minimalism and malleability principles, shipping with memory, SQLite, and JSONL storage backends plus a conformance suite for custom ones. The goal is a harness that survives failures, supports infinitely long conversations, and lets multiple humans steer the same agents.
