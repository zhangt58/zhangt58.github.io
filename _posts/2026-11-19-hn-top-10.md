### 2. [Ruby2ßhell: Pre-authentication RCE on stock Rails](https://verialabs.com/ruby2shell/)
⭐ 178 💬 68 👤 jdns
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50556287)

Ruby2ßhell is a pre-authentication remote code execution vulnerability in Ruby that affects stock Rails and Sinatra applications by default. It is caused by a one-byte heap overflow when upcasing the ß character in certain single-byte encodings, allowing attackers to corrupt memory and potentially execute arbitrary code. The issue is fixed in Ruby 3.3.14, 3.4.13, and 4.0.10, and affected self-hosted products should be updated to vendor releases.

⭐ 82 💬 14 👤 ghostfoxgod
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50557537)

Blobasaur is a sharded, distributed blob storage server built on SQLite to handle high-throughput reads and writes of multi-megabyte JSON blobs. The system achieves thousands of operations per second on commodity hardware while keeping latency in single-digit milliseconds.

### 6. [SSD prices will start going down the second half of next year](https://www.drivevault.io/blog/when-will-hard-drive-prices-come-down.html)

### 8. [Unauthenticated remote code execution in Nginx](https://www.wiz.io/blog/nginx-http2-rce-vulnerabilities)
⭐ 1412 💬 606 👤 speedping
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50547374)

Researchers identified two critical unauthenticated remote code execution vulnerabilities in NGINX that can allow attackers to compromise servers, steal data, or disrupt services when HTTP/2 is enabled. The flaws exist in NGINX itself, so affected deployments can be exposed even if the hosted applications are secure. F5 has released security updates, and organizations should patch affected NGINX installations.

### 9. [15M web servers on one VM – smoltcp, DPDK, AF_XDP](https://kapteko.com/15-million-webservers/)
⭐ 190 💬 26 👤 fessguid
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50556533)

The article explores running 15 million web servers on a single virtual machine with 10GB of RAM and one CPU core by examining how a basic web server relies on kernel syscalls such as listen, accept, recv, send, and close. It then analyzes TCP port limitations and discusses high-performance networking approaches, including smoltcp, DPDK, and AF_XDP, to overcome traditional operating system and hardware constraints. The goal is to show how software-level optimizations can enable massive concurrency on modest hardware.

### 10. [Do not buy RAM, compress](https://curiousbits.nl/blog/do-not-buy-ram-compress/)
⭐ 51 💬 38 👤 Ecno92
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50557661)

The article recommends using zram memory compression instead of buying more RAM to handle increased memory demands from parallel AI workloads. It explains that zram is already common on Windows, macOS, and Android but is not enabled by default on many Linux distributions, and it can provide large capacity gains with modest CPU and latency costs. A practical test shows compressed memory allowing more applications to run than physical RAM would normally support.
