### 2. [Faster than earcut: triangulating 3.7M map polygons in 489 ms](https://globus.software/blog/2026/10/16/cutting-map-polygons/)
⭐ 43 💬 3 👤 molind
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50193170)

The article describes earstrip, a lightweight polygon triangulation library released from a map engine that outperforms earcut by 14% in C++ and 1.4 to 2.1 times in the browser. It explains how the authors replaced a slower constrained Delaunay triangulator with an optimized ear-clipping approach, enabling 3.7 million map polygons to be triangulated in 489 ms.

### 3. [WorldTUI: I trained a 360M model to pretend to be a terminal](https://simedw.com/2026/10/21/world-model-terminal/)
⭐ 241 💬 78 👤 alphax314
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50190363)

A 360M-parameter language model was fine-tuned to simulate a terminal by predicting screen changes from raw keypresses, without an actual shell or filesystem. Trained on recorded terminal sessions, it can mimic commands, editors, and simple games while maintaining a consistent state across interactions. The approach treats the terminal as a character grid and focuses on repairing errors and decoding screen rows in parallel.

### 5. [Achieving AI-style reasoning without an LLM](https://fleetingswallow.com/minotaur-ai-deep-dive-achieving-reasoning-without-a-language-model/)
⭐ 36 💬 12 👤 edwardchalk
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50192868)

Minotaur is an AI architecture that performs complex reasoning without a language model or GPU by operating on the structure of a system rather than imitating human text. The article argues this approach can provide checkable, replayable reasoning and matches language-model performance on certain blind tests.

### 9. [Compromised LiteLLM 1.107.0 on PyPI Installs a Credential Stealer and Backdoor](https://safedep.io/litellm-pypi-compromise-credential-stealer-backdoor/)
⭐ 530 💬 172 👤 abhisek
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50181114)

A compromised LiteLLM 1.107.0 release on PyPI installed a credential stealer and remote code execution backdoor into site-packages, executing in any Python process on the host. The malicious code collected SSH keys, cloud and CI/CD secrets, browser passwords, and LLM provider keys, and could download and run additional attacker code. PyPI removed the release and affected Docker images, while earlier release candidates and certain companion packages were reported clean.
