### 1. [Google Will Make AI Agents Use Its MCP Servers. The Gmail One Can't Send Email](https://techstackups.com/articles/google-workspace-ai-agents-mcp/)

[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50653477)

Google is requiring AI agents that access Workspace to use its MCP servers, while non-AI applications can continue using the existing REST APIs. The Gmail MCP server can search, read, draft, and label mail, but it cannot send, reply, forward, or edit drafts, which remain restricted to partner access. The policy also limits how agents handle Workspace data, requiring deletion when users disconnect and capping retention of derived data such as embeddings and memory indexes.

[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50644817)

1Password reported that an attacker accessed an employee's corporate GitHub account and used it to push malicious code and download non-secret customer account metadata, along with private source code and CI/CD secrets. ### 5. [Lions' Commentary on Unix: Why It Was Secretly Copied for 20 Years](https://fosscomics.com/posts/17.%20Lions%27%20Commentary%20on%20Unix/)
⭐ 118 💬 17 👤 joonehur
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50651719)

Lions' Commentary on Unix began as lecture notes explaining the Unix Version 6 kernel source, and it spread widely among schools and research institutions. After AT&T tightened licensing rules around source-code teaching, the book became tightly controlled, leading students to rely on unauthorized photocopies for about two decades. The commentary became an essential, though unofficial, way for a generation to study Unix internals.

### 10. [Minipg: PostgreSQL as a Single Executable](https://progrium.github.io/minipg/)
⭐ 156 💬 24 👤 rguiscard
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50650892)

Minipg packages PostgreSQL as a single executable that uses a .pgdb directory to store all database data, configuration, and credentials, eliminating manual server setup. It automatically starts and stops a Postgres server as needed and runs the database through h9, which executes Alpine Postgres binaries directly on the host hypervisor without a Linux kernel, VM image, or Docker. The tool provides simple commands for shells, queries, app integration, and backups, though it is still early and may be slower than native Postgres.
