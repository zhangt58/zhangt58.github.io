### 2. [Unauthenticated remote code execution in Nginx](https://www.wiz.io/blog/nginx-http2-rce-vulnerabilities)
⭐ 1133 💬 507 👤 speedping
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50547374)

Two critical unauthenticated remote code execution vulnerabilities in NGINX itself can allow attackers to take control of affected servers, steal data, tamper with websites, or disrupt services, even when application code is secure. Both flaws require HTTP/2 to be enabled and affect widely used deployments that route traffic to applications and APIs. Organizations should identify exposed servers and apply the released security updates.

### 3. [Multiple vulnerabilities in Regexp and String case conversion](https://www.ruby-lang.org/en/news/2026/11/18/multiple-vulnerabilities-in-regexp-and-string/)
⭐ 57 💬 9 👤 runesoerensen
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50554038)

Seven security vulnerabilities were found in Ruby’s regular expression engine and string case conversion, including heap buffer overflows, double frees, integer overflows, and out-of-bounds reads. Some flaws can be exploited for remote code execution or information disclosure when processing crafted strings or regular expressions. The issues are fixed in Ruby 4.0.10, 3.4.13, and 3.3.14, and upgrading is strongly recommended.

### 8. [AI agents ask better questions than KPMG accountants in audit trial](https://europeanbusinessmagazine.com/ai-agents-better-questions-kpmg/)
⭐ 352 💬 160 👤 Betelbuddy
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50547777)

KPMG’s Project Exponential used more than 100 AI agents to examine the accounts of a UK-listed company, finding that the agents sometimes investigated financial issues more deeply and asked better questions than the human audit team. ### 9. [DNS resolvers are the wrong place to fight piracy](https://techstackups.com/articles/quad9-leaves-france-dns-blocking/)
⭐ 598 💬 223 👤 ritzaco
[🔗 Discuss on HN](https://news.ycombinator.com/item?id=50545958)

Quad9, a Swiss non-profit public DNS resolver that blocks malware and phishing domains, will stop serving France after a Paris court fined it for refusing to block pirate sports-streaming sites on behalf of beIN Sports. With numerous similar cases pending, the organization says withdrawing is the only financially viable option. The article argues that forcing DNS resolvers to block piracy targets is an inappropriate and harmful way to address copyright infringement.
